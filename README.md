# groundwater-dynamics-punjab
Spatio-temporal analysis of groundwater dynamics across Punjab, Pakistan using GRACE/GRACE-FO data and Google Earth Engine.
About The Project:

As one of the world's most heavily irrigated agricultural regions, Punjab relies intensely on groundwater extraction to supplement surface water canals. Unregulated pumping has led to severe aquifer depletion across the Indus Basin. This project tracks long-term terrestrial water storage dynamics across Punjab, Pakistan, using satellite gravimetry data from NASA's Gravity Recovery and Climate Experiment (GRACE) and GRACE Follow-On (GRACE-FO) missions spanning from 2003 through 2024.
